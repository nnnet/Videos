# Документация Videos

Карта, а не текст. Здесь только указатели — содержание лежит в листьях.
Правило дерева: **README → область → лист**. Три уровня, глубже не растим.

## Куда идти

| Вопрос | Куда |
|---|---|

| Как это запускать, чинить, деплоить | [operations/](operations/index.md) |

## Как читать

Открывать сверху вниз и останавливаться, как только ответ найден.
Лист самодостаточен: если для ответа пришлось открыть три файла — лист
написан плохо, его надо переписать, а не добавить четвёртый.

## Как писать

- **Один лист — один вопрос.** Заголовок листа формулируется как вопрос
  или как задача («Как добавить провайдера»), не как существительное
  («Провайдеры»).
- **Ссылка вместо копии.** Повторённый абзац устаревает в одном месте из
  двух и начинает врать. Ссылайся.
- **Лимиты строк** (проверяются `agent-ops docs-check`):
  README ≤ 50, `<область>/index.md` ≤ 100, лист ≤ 200.
  Лист перерос лимит — значит внутри было два вопроса, режь на два листа.
- **Факт с адресом.** Утверждение о коде сопровождается путём
  `file.py:42`, иначе его невозможно проверить и через месяц никто не
  знает, правда ли это ещё.
- Шаблон нового листа — [`_leaf-template.md`](_leaf-template.md).

## Что сюда не кладут

Историю изменений (её держит git), скопированный вывод команд,
черновики и планы работ (они в `.claude/plans/`).
