# Решения Videos

Почему сделано так, а не иначе. Область существует ради одного:
чтобы через полгода никто не «улучшил» систему обратно в вариант,
который уже пробовали и отвергли.

## Правила

- Одно решение — один файл `NNNN-kebab-заголовок.md`, нумерация сквозная.
- Запись **не редактируется** после принятия. Передумали — новая запись
  со статусом `заменяет NNNN`, старая получает `заменено NNNNN`.
- Шаблон — [`0000-template.md`](0000-template.md).
- Отвергнутый вариант и **причина отказа** обязательны: без них запись
  бесполезна, спор начнётся заново.
